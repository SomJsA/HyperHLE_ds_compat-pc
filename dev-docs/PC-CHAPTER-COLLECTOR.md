# PC 全章节诊断采集包

此版本交付给外测玩家完整游玩所有章节。目标优先收集能指导最终优化的数据；不等于最终性能验收，也不保证一次通关后所有问题都能修好。

## 玩家怎么用

1. 解压到新目录，运行 `DeadSpace Launcher.exe`。新配置默认开启自动诊断及「超级：全程活动 + 慢调用定位」。已有用户设置继续保留；请在「兼容与诊断」核对开启，并选超级档。
2. 按自己的节奏正常从第一章玩到最后。可以退出休息、换画质、读档或死亡；每次启动独立记录，不需要一次连续通关。尽量顺路访问门、电梯、商店、工作台和其他机关。默认不采集截图、录屏、逐键输入、账号或存档，不自动上传。
3. 看到异常可以在启动器填写简短备注并「标记问题」，这只是额外线索；严重游戏长帧会自动留存异常前约30秒、后约3秒的可用数据。只要正常玩即可，不要求反复重做动作。
4. 所有测试结束后退出游戏，在同页「导出诊断 ZIP」。默认勾选全部会话；三个槽位存档和截图附件由玩家明确勾选。把导出的 ZIP 交回，不需要手工找散落日志。导出不会删除原记录。
5. 如果超级档明显妨碍推进，可改增强或基础并重新启动，再在备注里说明。系统自身会在过载、积压、磁盘不足时降频或暂停详细采集，明确保留缺口；无数据不代表无故障。日志总量不设固定上限，磁盘低于256MiB时停止详细写入，保留已有文件。

默认资料位置：系统「文档 / DeadSpace IOS移植」，布局v1；完整配置与存档兼容约定见 `STORAGE-COMPATIBILITY.md`。每次游玩的诊断在该资料根 `diagnostics/play-sessions/session-*`。沿用旧显式资料根时以启动器所选位置为准。不要把诊断包解压覆盖已有存档，不用删除旧目录。

## 本版新增的诊断

- 统一单调时间轴：原生 present 全帧时间、阶段/状态、可可靠识别的章节事件、间隔位置/提示状态、加载与模态事件、请求与实际生效配置、内存与后台查询的进程累计CPU时间。
- 每秒场景活动计数与慢调用：guest文件读取、IPA首次解压与缓存命中、图像/PVRTC解码、HD查找/缓存复制、mip、纹理/缓冲上传、绘制数量、显式着色器编译/链接、已有ReadPixels/Finish/Flush调用。诊断自身不会发起读屏或GL查询。
- JIT翻译过程的代码读取活动。它能提示进入新代码路径，但不是编译耗时、编译块数或实际执行指令数。
- 部分固定功能渲染状态组合首次出现的指纹；只跟踪后端已有setter参数，无屏幕识别、顶点/纹理内容扫描或新驱动查询。每上下文最多4096指纹，溢出计数明确。它不是完整着色器键，也不能证明驱动编译；矩阵、灯光/材质、完整combiner和直接GL辅助绘制等未完全覆盖。
- 慢调用所属的进程内线程标签；HLE导入符号绑定与不可变IPA成员索引/源码行映射随会话导出，便于开发者解码。线程标签不是操作系统线程ID或调用栈。
- 采集线程与其他工作线程的采集耗时分别记录，后台写入/队列/降频/丢弃/缺口继续自监测。超级档允许更高采集预算：200ms/秒开始降频、500ms/秒暂停详细记录；增强档50ms/200ms，基础档沿用1ms/4ms。首轮真实菜单中85–135ms/秒的采集耗时会耗尽旧超级10ms/40ms预算并反复暂停，因此数据优先包提高了明确显示的阈值；它可能明显降低体验。预算是初始保护值，真实影响另用同场景A/B，不能宣称零开销。

嵌套CPU wall span相互重叠，不能相加当独占函数成本；协作调度中的HLE等待可跨越很多present，不能读成同样时长的卡死。GPU完成时间当前没有可靠计时器；记录的是提交与CPU调用返回耗时，驱动内部固定功能着色器编译仍需结合首次使用、长帧和其他活动排查。无全局预编译已完成的承诺。

本采集包不修改原IPA、发行存档模型、游戏时钟或动作门槛，不用帧生成冒充真实FPS。包内纹理档位和现有文本/字号/修复保留。正式双端完整性能、武器音频、跨关、实体手柄/额外硬件与最终验收仍开放。


## 可直接转发给游玩者的提交要求

请退出游戏，启动器「兼容与诊断 → 导出诊断 ZIP」，保留默认的全部会话勾选，把生成的 **DeadSpace-Diagnostics-*.zip** 上传交回即可。

如果手工收集：点同页 **打开诊断文件夹**，将这个 **play-sessions** 文件夹内的全部文件和全部子文件夹一起压缩上传，不要只选incident、最新一次或单个CSV。默认路径是系统 **文档 / DeadSpace IOS移植 / diagnostics / play-sessions**；Windows重定向文档目录或旧显式资料位置时，以按钮实际打开的位置为准。文件夹内每个session都是一次游玩，分次通关的所有会话均有用。无需交整个游戏3GB分发包；截图与三个槽位存档可在导出界面自行明确选择附带。
