# R13 经验

1. 检查对象归属，不按相同 offset 认为字段相同。HUD+1cc 与 Player+1cc 并不等价；上下文动作必须与原版路径核对同一 owner。
2. SDL 事件分派已 consume，并不代表轮询状态也已 consume。语义 A/LB 与 legacy touch 共用一个物理按钮时，两条通道都要隔离；跨 UI 所有者的 held 状态尤其容易重放。控制 inbox 的键盘测试不能覆盖这一点，必须增加真正 SDL 虚拟控制器状态测试。
3. 被动指针位置不能覆盖原生方向选择。没有实际轴移动不生成 hover；初次选择应明确写到原生 SetSelected，不能只赋宿主 focus。
4. 提示锚点应跟语义按钮。卡片页原生勾不在根名称 map，不能回退到当前分页箭头来表示确认。
5. 离线入口要在原生 hit-test 前禁用。只从键盘选择列表移除 DLC，鼠标仍能点进去。调用原版 SetEnabled 才能连同禁用外观一起生效。
6. 快速导航与滚动要串行/合并最新请求。可见性还要服从原生滚动上限与边框：实测 row5=[19,239,468,27]，clip=[13,153,438,110]，scrollY=-53，底3px不可再卷入。严格整框条件会无限等待；保留数值回归样例，不能靠继续加 swipe 消除。
7. 回归脚本 close 后可能先观察 closed 再收到同序号回执；这是清理竞态，不能把完整功能路径通过伪装为失败，也不能直接丢掉错误证据。保留原始记录、修复脚本并重跑。

代码注释保存修复原因；后续翻译、渲染或主线整合不得整文件覆盖。R12/R13 真人验收通过后才显式暂存本轮路径，未知脏改动保留。
