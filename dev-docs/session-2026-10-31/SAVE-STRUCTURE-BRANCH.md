## 已实现

入口：[`tools/save-lab/README.md`](../../tools/save-lab/README.md)。

1. **结构解析与对照**：严格验证 SBIN v2、各区段 FNV-1、OHDR、STRS、对象边界、字段偏移、
   引用、列表和根图循环。导出所有已支持类型的路径和值、对象成员和列表长度，提供语义 diff。
2. **标量与扩容编辑**：按路径修改数值/布尔/float32/字符串；可以扩充 STRS，增删背包条目、
   替换字符串或数值列表。写回重新校验并重解析，命令只创建新文件，不覆盖输入或已有输出。
3. **对象模块**：模块 JSON 导出/导入、向对象添加字段、移除字段。跨档按名称重映射 STRS，
   按局部图重映射 OHDR，保留移植图内的共享引用。新对象追加到 DATA，原始不相关状态不重排。
4. **整组冷插拔**：Documents 快照库、逐文件哈希/成员校验、切换前整组备份、同目录暂存与
   重命名发布、异常回滚、将备份再次作为配置恢复。覆盖 var 外依赖、隐藏普通文件与空目录。
   进程检查失败或存在 touchHLE 时拒绝切换；拒绝路径越界、重叠、链接和目录联接。

当前是可运行命令行后端，还没有接入启动器图形界面或 Android 存档页。

## 已核实的格式纠错

对照主线工作树的 `SaveDocument.cs` 与真实文件，而非照抄早期 `SAVE_FORMAT.md` 的猜测：

- 根对象由 `OHDR[0]` 指定。Survival 和 Achievements 的根可能在 DATA 尾部。
- 字段值偏移相对于所属对象；根在 DATA+4 时，某些偏移看起来像绝对地址只是巧合。
- 校验是 FNV-1（乘后 XOR），不是 FNV-1a，也不是区段名称哈希。
- `0D` 是本文件 STRS 的 u16 名称 ID；跨文件不能直接照搬数字。
- settings 的 `dlc_modules` 是引用对象，检查点的同名字段是已应用字符串 ID 列表，均不是位掩码。
- 13 字节的末尾布尔对象只拥有一个有效字节；其后 CD 填充不随标量修改被覆盖。
- 背包 `10` 列表使用已确认的 `u16 name/u16 padding/u32 count` 编码；不把这个解释套到未知结构。
