## 本轮修复及永久约束

- 暂停菜单使用原版 HUD `+0x1294` WidgetHandler 的实际按钮、边界和 SendAction。
  HUD 2、3 都是暂停变体；原版不会在动画结束后把 2 自动提升为 3。
  必须按原生动画完成和当前 handler 绘制判断就绪。方向键／十字键选项，
  E／Enter／A 确认，Q／Escape／X／B／Back 返回或继续。恢复按钮不进入方向焦点。
- 暂停的选项／帮助不是前端 LayerMainMenu，而是 HUD 4／5 的 `+0x24c` 布局，
  使用 `+0x1340` 动画器和 `+0x132c` 布局所有者。必须继续占有输入，不能让 X
  旋转或武器请求落到背后。上下按控件顺序选择，左右调整或操作所选翻页箭头；
  E／Enter／A 调用原版确定，Q 调用原版返回。原生鼠标拖动保留。
  Slider 的虚表 `+0x2c` 是类型信息，不能当按钮调用；其两个 SliderButton
  SendAction 又是空实现。方向调整须取原生子按钮位置，通过内部触摸事件运行
  原版步进／限幅／回调，不直接写值；禁用的加号不能被误当减号。
  原版实际使用 SlideFill（继承 Slider），且含 Minus／Plus 和 Selector 子按钮。
  OptionsWindow `+0x70` 指向 OptionsPanel，其 `+0x5c/+0x60` 为控件向量；
  这些控件不在根 handler 名称表中，父控件 active rect 可能为空，要从子按钮还原。
  子按钮坐标须加滚动视口原点与原生滚动量，并按当前页裁剪；不能选到其他页控件。
  WidgetHandler `+4/+8` 是原版 Draw 的宽高参数，绝不能再次当坐标平移。
  就绪须使用布局阶段 `+0x1328 == 2` 和实际绘制：原版在 elapsed == duration
  时 IsFinished=true，进入阶段 2 后不再更新动画，IsAnimating 字节却可能仍为 1。
  不能额外等待 IsAnimating=false，否则选项页永远不响应。
  原生滑条还会忽略 60 FPS 下只有一帧的按下／抬起；专用 UI tap 保持三帧，
  复用原版重复／步进逻辑，已有待释放的合成点击时不叠加。普通游戏点击时长不变。
- 删档固定为物理 Delete／手柄 Start，只在原生 `BTN_DELETE` 有效时派发。
  保留原版确认页；普通确认键不映射删除，方向焦点跳过删除按钮。
  提示继续使用 CC0 Kenney 贴图，新增 Delete 与 Start，不手绘代用品。
- `SetSelected` 只改变按钮视觉，不能当作改变原生菜单选择。章节模式由
  LayerMainMenu `+0x350/+0x354` 保存，档案由 `+0x1a8` 保存。方向选中和
  确认前经原生按钮事件同步，已相符则不重复发送，防止触发原版双击进入。
  不直接写这些字段；原版 SetSelectedProfile 仍负责读取对应检查点。
- 游戏中十字键上／右／下／左依次映射键盘 1／2／3／4 的原生武器动作：
  线形枪／等离子切割枪／绞肉枪／取芯器。任一方向按住 450 ms 切第五把大脉冲。
  长按只发一次，放开不退回旧武器；同时按住以后按者为准。
- 键盘和手柄共享 120 ms 切枪冷却。冷却内保留最后一次请求，暂停不被冷却阻挡。
  UI、失焦、取消输入会清掉待发和长按状态；菜单里的十字键仍负责导航。
  武器仍调用已验证的原生 HUD 事件，不伪造触摸或改武器内存。
- 自动验证仅使用专用 control inbox；显式 BACKGROUND_TEST 且有 inbox 时，
  SDL 窗口从创建起 hidden，屏蔽物理手柄事件。此开关不进入普通启动默认。

## 真人验收清单

1. 在选档页左右切档，确认高亮与实际档案一致。对有内容的测试档按 Delete／Start，
   应出现原版确认页；先取消，确认存档仍在。不要对自己的唯一存档做删除实验。
2. 选中“章节”，按 E、Enter 或 A，应进章节选择而非剧情；返回后再选剧情。
3. 游戏中暂停，方向键／十字键应遍历重新开始、选项、帮助、退出。
   确认应只操作当前项；取消／再次 Back 应恢复游戏。原生鼠标操作保留。
4. 四个十字键各短按一次；任一方向长按应切第五把。按住一个再按另一个，
   应以第二个为准，放开不能跳回第一把。快速交替数字键也不应按旧请求排队乱切。
5. 暂停或失焦后恢复，不能突然切第五把、继续跑动或触发后台交互。
6. 顺带回归工作台／商店、G 定位／Z 转身、C 静滞和正常退出。
